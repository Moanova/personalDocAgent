## Plan d'implémentation

### Sous-tâches
1. **`search_documents(conn, filters: SearchFilters) -> list[dict]`** : requêtes SQL sur `document` + jointures (`document_category`, `issuer`, `document_subject`) selon les filtres remplis (category_id, issuer_id, date_from/to sur `dc_date`, dc_type, status, keyword) ; retour : doc_id, dc_title, source_file jamais exposé... (chemin interne non exposé au prompt — retourné en interne, filtré avant envoi au modèle : voir T7.2) — retour dict {doc_id, dc_title, dc_date, dc_type, status, issuer_label, category_label}.
2. **`search_fulltext(conn, expression) -> list[dict]`** : FTS5 `conversion_fts MATCH ?` avec `snippet()` pour l'extrait ; retour {doc_id, dc_title, excerpt}.
3. **`read_document(conn, doc_id) -> dict`** : texte extrait (conversion la plus récente) + description + métadonnées ; textes longs tronqués (ex. 4000 caractères) avec extrait autour des occurrences de la recherche.
4. **`aggregate(conn, restricted_query) -> dict`** : whitelist de champs (`count`, `sum` sur clé `attributes` via `json_extract`) + filtres optionnels (issuer_id, category_id, date range) ; champ non whitelisté → `ValueError`.
5. **Tests** `tests/unit/test_query_tools.py` : TU-46 à TU-49 sur base seedée (documents, conversion, FTS, catégories, émetteur, attributes avec montant).
