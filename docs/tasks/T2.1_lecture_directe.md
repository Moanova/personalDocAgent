## Plan d'implémentation

### Sous-tâches
1. **Dispatch par extension** dans `read_direct(path)` : une extension de la voie `direct_read` (selon `config/routing.yaml` : `.txt`, `.md`, `.html`, `.htm`, `.docx`, `.odt`) est routée vers le lecteur correspondant ; toute autre extension lève une `ValueError` avec le chemin en contexte.
2. **Lecteurs** :
   - TXT / MD : `path.read_text(encoding="utf-8")`.
   - HTML : BeautifulSoup — suppression des balises `script` et `style`, puis `get_text(separator="\n")`.
   - DOCX : python-docx — parcours des paragraphes puis des tableaux.
   - ODT : odfpy — `odf.opendocument.load` puis `odf.teletype.extractText` sur chaque élément de texte.
3. **Construction du contrat** : `AcquisitionResult(source_file=str(path.resolve()), route="direct_read", text=..., model=None, conversion_date=datetime.now(timezone.utc).isoformat())`.
4. **Erreurs de lecture** (fichier illisible, encodage invalide, format corrompu) : `ValueError` avec le chemin en contexte — pas d'exception brute, pas de lecture partielle silencieuse.
