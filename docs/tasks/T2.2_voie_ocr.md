## Plan d'implémentation

### Sous-tâches
1. **Client Mistral paresseux** : `_client()` construit `Mistral(api_key=os.environ["MISTRAL_API_KEY"])` à la demande ; variable absente → `RuntimeError` explicite, aucun appel réseau. `convert(path, client=None)` accepte un client injecté (tests mockés, aucun accès réseau).
2. **`convert(path, client=None) -> AcquisitionResult`** dans `acquisition/ocr.py` :
   - upload du fichier local : `client.files.upload(file={"file_name": path.name, "content": path.read_bytes()}, purpose="ocr")` → `file_id` ;
   - appel OCR : `client.ocr.process(model="mistral-ocr-latest", document={"type": "file", "file_id": file_id})` (SDK mistralai 3.4.0 vérifié : `Ocr.process`, `OCRResponse.pages[].markdown`) ;
   - texte = concaténation des `page.markdown` (séparateur `\n\n`, pages triées par `index`) ;
   - contrat : `AcquisitionResult(source_file=str(path.resolve()), route="ocr", text=..., model="mistral-ocr-latest", conversion_date=<ISO 8601 UTC>)` ;
   - erreur API → `ValueError` contextualisé (chemin + cause).
   - Note : les scores de confiance par page (`page.confidence_scores`) ne sont pas persistés — ni le contrat `AcquisitionResult` ni la table `conversion` n'ont de colonne dédiée (point de conception à trancher plus tard si besoin).
3. **Persistance dans `conversion`** (helpers route-neutres, dans `acquisition/ocr.py` selon le kanban) :
   - `save_conversion(conn, doc_id, result) -> bool` : `INSERT OR IGNORE INTO conversion(doc_id, extracted_text, model, conversion_date)` ; retourne `True` si inséré, `False` si déjà présent (idempotent, PK `doc_id` + `model`) ; les triggers alimentent `conversion_fts` automatiquement ;
   - `load_conversion(conn, doc_id, model) -> str | None` : relecture sans nouvel appel API (« ne jamais re-payer une conversion », `conception.md` §9.5).
