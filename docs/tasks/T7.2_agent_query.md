   - tool inconnu / arguments invalides → `ValueError` explicite, boucle interrompue proprement (TU-52) ;
   - garde-fou : boucle bornée (ex. 10 itérations max).
3. **Tests** `tests/unit/test_query_agent.py` : TU-50 (client fake : 1er tour tool_call `search_fulltext`, 2e tour texte final ancré), TU-51 (historique JSON + journal), TU-52 (tool invalide).
