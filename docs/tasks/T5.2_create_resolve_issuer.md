## Plan d'implémentation

### Sous-tâches
1. **`create_issuer(conn, label, linked_category=None) -> int`** dans `issuers.py` : idempotent — si un émetteur de label normalisé identique existe, renvoyer son id ; sinon `INSERT INTO issuer (label, linked_category)` ; `IntegrityError` (label UNIQUE) → relire et renvoyer l'id existant.
2. **`resolve_issuer(conn, match, candidate, confidence, policy) -> IssuerMatch`** :
   - `known` / `ambiguous` → renvoyé tel quel (l'arbitrage ambigu est agentique/humain, hors périmètre) ;
   - `unknown` + `confidence >= policy.auto_confidence_threshold` → `create_issuer(conn, candidate)` puis `known` (création automatique, cf. `conception.md` §4 : évite la prolifération de quasi-doublons) ;
   - sinon → `unknown` (file d'attente : `issuer_id` NULL, validation humaine ultérieure).
3. **Tests** `tests/unit/test_issuers.py` : TU-38 — confiance ≥ seuil → créé + known ; < seuil → unknown ; `create_issuer` idempotent (même label → même id, une seule ligne).
