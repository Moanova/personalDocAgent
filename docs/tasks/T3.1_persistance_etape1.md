## Plan d'implémentation

### Sous-tâches
1. **Table MIME** `_MIME_BY_EXT` dans `pipeline.py` : `.pdf`→`application/pdf`, `.txt`→`text/plain`, `.md`→`text/markdown`, `.html`/`.htm`→`text/html`, `.docx`→`application/vnd.openxmlformats-officedocument.wordprocessingml.document`, `.odt`→`application/vnd.oasis.opendocument.text`, `.jpg`/`.jpeg`→`image/jpeg`, `.png`→`image/png`, `.tif`/`.tiff`→`image/tiff`, `.webp`→`image/webp` ; repli `application/octet-stream`.
2. **`persist(conn, result: AcquisitionResult) -> WriteResult`** :
   - `source_file` canonique = `result.source_file` (déjà résolu par `read_direct`/`convert`) ;
   - si `is_duplicate(Path(source_file), conn)` → `WriteResult(doc_id=<existant>, written=False, reason="duplicate")` ;
   - sinon `INSERT INTO document (source_file, date_added, status, dc_format)` avec `date_added = datetime.now(timezone.utc).isoformat()`, `status='active'`, `dc_format = _MIME_BY_EXT.get(suffix, "application/octet-stream")` ; `doc_id = cursor.lastrowid` ;
   - `save_conversion(conn, doc_id, result)` avec `model = result.model or result.route` (colonne `model NOT NULL` — pour la voie directe, `model=None` donc on persiste la route `direct_read`) ;
   - retour `WriteResult(doc_id=doc_id, written=True)` ;
   - `sqlite3.IntegrityError` (course) → `WriteResult(written=False, reason="duplicate")`.
3. **Tests** `tests/unit/test_persist.py` : TU-21 (champs déterministes + `WriteResult` + ligne `conversion`), TU-22 (idempotence doublon), TU-23 (FTS alimenté via les triggers), TU-24 (mapping MIME).
